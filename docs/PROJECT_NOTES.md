# 项目说明与面试准备

## 可以写进简历的表述

**ACT 机器人模仿学习仿真实验｜LeRobot / MetaWorld / PyTorch / DDP**

- 基于 LeRobot 实现推物块任务的专家演示采集、LeRobotDataset 数据检查、ACT 训练与闭环评测流程，采集 500 条训练演示和 100 条验证演示。
- 配置 8 张 RTX A6000 的 DDP 训练，每卡 batch8、全局 batch64，完成 5000 次参数更新；建立 checkpoint 验证与选择流程。
- 在 100 个未用于训练或选模的初始化种子上，选定策略完成 100/100 次任务；加入随机控制器与规则专家对照，保存逐局指标与回放。

这些是项目的实际结果。面试时应根据自己的掌握程度调整表述，并说明核心 ACT 实现使用开源框架，不声称提出了新算法。

## 需要讲清楚的六个问题

1. **专家和学生看到什么？** 专家使用完整仿真状态；学生只看图像和机器人自身状态。物块和目标位置需要从图像中推断。
2. **为什么动作标签是 `[B,32,4]`？** 每个样本的当前观测对应当前及之后 31 个专家动作，DataLoader 再沿样本维堆叠。
3. **轨迹末尾怎么处理？** 标签补齐并产生 `action_is_pad`。动作损失只对有效分量求平均；VAE 编码器也接收 padding mask。
4. **ACT 为什么训练和推理不同？** 训练时 VAE 编码器根据状态、专家动作估计潜变量分布；推理时没有专家动作，使用零潜变量。
5. **8 卡训练了几个模型？** DDP 在各卡放置同一模型副本，读取不同样本并同步梯度，最终训练一套参数。没有做 1 卡与 8 卡的受控速度对比，因此不声称八倍加速。
6. **为什么选 4000 步而不是最后一步？** 多个 checkpoint 在验证场景均成功 20/20，按事先确定的次级指标选择完整验证集动作 L1 更低者。测试集只在选择后使用。

## 本项目的边界

- 是单任务离线模仿学习，不是强化学习，也不是语言条件 VLA。
- `100/100` 是有限测试集中的观测结果，不代表所有新场景都必然成功。
- 随机种子不同但视觉、物理参数分布相同；不构成域外泛化或 sim-to-real 证据。
- 只完成一次正式训练种子，没有多个训练种子的方差统计。
- 从早期 20 条演示的失败实验到本项目，同时改变了数据量、模型配置和训练量，不能把提升归因于单一变量。

## 建议继续做的实验

先固定模型、全局 batch、更新次数和评测种子，只改变演示数量，比较 50 / 100 / 500 条的成功率；再独立比较 chunk 和动作执行长度。为每组增加多个训练种子，并保存失败案例。
